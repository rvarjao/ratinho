# Escape do Ratinho

Jogo de lógica em HTML, CSS e JavaScript puro, sem dependências externas, inspirado no quebra-cabeça físico Escape Ratinho.

## Jogar

Abra o `index.html` no navegador, ou publique o repositório pelo GitHub Pages.

- 12 níveis progressivos recriados (não são os diagramas oficiais do fabricante).
- Arraste as peças com mouse ou toque; pelo teclado, selecione com W A S D e mova com as setas.
- Botões de desfazer e reiniciar.
- O objetivo é levar o bloco 2×2 do ratinho até a saída central inferior.
- Laboratório de IA com aprendizagem por reforço guiada por demonstração, estatísticas e três velocidades.
- Solucionador por busca exata para demonstrar o menor número possível de movimentos.

## Publicar no GitHub Pages

Em **Settings → Pages**, selecione **Deploy from a branch**, branch **main** e pasta **/(root)**.

Endereço previsto: https://rvarjao.github.io/ratinho/
